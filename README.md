# LuV

Statische Web-App fuer Leistungs- und Verhaltensbeurteilungen.

## Nutzung

Die Anwendung laeuft vollstaendig im Browser. Lokal am besten ueber einen kleinen Webserver starten, z. B. mit `python3 -m http.server`.

## Projektstruktur

- `index.html` enthaelt die Seite.
- `styles/` enthaelt Layout, Basis- und Druckstile.
- `src/` enthaelt die App-Logik und Views.
- `data/luv-data.js` enthaelt die fachlichen Daten.
